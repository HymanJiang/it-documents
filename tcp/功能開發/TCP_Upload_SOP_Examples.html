TCP Upload — SOP 設定範本

常見上傳設定情境，供製作 SOP 或範本參考

欄位設計說明

Commission Rate sheet（共 33 欄，三區塊）

基本資訊（7 欄）：Site、Email、Group Name（選填，多計算方式時區分群組）、Commission Type（IND＝直接用自己 Sales_ID／Leader＝透過 Sales ID Config）、Achievement Rate Threshold（累積達成率門檻）、Achievement Rate Threshold(Monthly)（選填，啟用每月獨立判斷）、GP（毛利率條件）。

Standard CR%（13 欄）：Commission Rate（預設 CR%）＋ Jan~Dec（各月可個別設定，留空沿用預設）。Monthly CR%（13 欄）：結構同上，用於月達成率門檻對應費率。

Sales ID Config sheet

Email、Group Name（對應 Commission Rate 群組，留空＝單一計算方式）、Sales ID、Jan~Dec（isActive 旗標：1＝該月啟用、0＝停用）。

Mapping sheet（業績觀看權限，非管理階層關係）

Email（要開放觀看的人）、Sales（被觀看對象 Email）。範例：主管 A 看業務員 B → Email=A、Sales=B。

RS sheet（報表篩選條件，對應報表抓 Revenue/Quota 作額外獎金依據；不含 Site）

Email、Group Name、Report、FOB_Local、Region、Entity、Sector、Prod_Group、Jan~Dec（各月數值，用途待確認）。

一、Group Name 使用邏輯

Group Name 是 Commission Rate、Sales ID Config、RS 三張 sheet 之間的關聯鍵，三張透過 Email + Group Name 對應。一種計算方式 → 留空；多種 → 用 Group Name 區分。

情境一：單一計算方式（Group Name 留空）

大多數業務員，只有一套固定 Commission Rate。Commission Rate 一列（Group Name 空、IND、Threshold 0.7、CR 0.05）；Sales ID Config 各 Sales ID 一列，Jan~Dec 全 1。

情境二：多種計算方式（Group Name 區分）

同一業務員負責不同性質 Sales ID，各套不同 CR%。範例：5 個 Sales ID，2 個 9%、3 個 4%。

EmailGroup NameTypeThresholdCR
john@example.comGroupALeader0.80.09
john@example.comGroupBLeader0.60.04

Sales ID Config：GroupA → S001/S002；GroupB → S003/S004/S005（各月 isActive 可不同）。

情境三：月份 CR% 各自不同

每月費率不固定，按月個別設定。Standard CR% 區塊：Commission Rate 為預設，若該月有填值則以月份欄位為準（例：預設 0.05，Jan/Feb 0.03、Mar 0.05、Apr 0.07…）。
