1. Commission Rate（CR% 費率）
QCommission Type 四種類型有什麼差別？▼
類型適用對象Sales ID 來源Sales ID Config 必要？
IND 一般個人業務員 系統自動從 eManager 同步 不需要
NOACC 無個人帳號的業務員，邏輯同 IND 系統自動同步 不需要（但支援 Delta 調整）
LEADER 主管或多 Sales ID 負責人 完全依 Sales ID Config 設定 必須設定（Full-truth 模式）
RS Report-based 業務員，依報表維度計算 不使用 Sales ID 不適用（改設定 RS Sheet）
建議一般業務員填 IND；主管或需要彈性控制多 Sales ID 的填 LEADER；依報表篩選維度計算的填 RS。
QAchievement Rate Threshold 是什麼？什麼時候要填？▼

這是年度累積達成率門檻。系統會以業務員的累積達成率與門檻比較：

  • 達成率 ≥ 門檻 → 套用 Standard CR% 計算獎金
  • 達成率 < 門檻 → 不套用（依業務邏輯處理）
填寫格式填入小數比例，例如 70% 門檻填 0.7。
Q什麼時候需要填 Achievement Rate Threshold(Monthly) 和 Monthly CR%？▼

當業務員需要每月獨立計算達成率，並套用不同費率時才需要填。

注意 Achievement Rate Threshold(Monthly) 和 Monthly CR%.Commission Rate 必須同時填寫，任一欄位留空，整個 Monthly CR% 區塊（所有月份欄位）都不會儲存。
欄位說明範例
Achievement Rate Threshold(Monthly)每月達成率門檻0.8
Monthly CR% → Commission Rate未達月門檻時的預設 CR%0.02
Monthly CR% → Jan ~ Dec各月可單獨設定（留空沿用 Commission Rate）0.02
QStandard CR% 有 Commission Rate 和 Jan~Dec，差別是什麼？▼

Commission Rate 是全年預設值；Jan~Dec 是各月份的個別覆蓋設定。

  • 若某月份欄位有填值 → 以該月欄位為準
  • 若某月份欄位留空 → 沿用 Commission Rate 的值
範例Q1 費率較低，其他月份維持預設 5%：
Commission RateJanFebMarApr ~ Dec
0.050.030.030.03（留空，沿用 0.05）
Q業務員中途調整費率，要怎麼更新設定？▼

有兩種方式：

  • Upload（批次）：在 Excel 中修改費率後重新上傳，系統以 Email + Group Name + Site 為 Key 執行 UPSERT（覆蓋更新）。
  • Data View（單筆）：進入 Data View → Commission Rate Tab，找到該筆資料點 Edit，直接修改後 Save。
注意若只要變更部分月份，建議利用 Jan~Dec 各月欄位逐月填寫，避免 Commission Rate 預設值自動覆蓋原有月份設定。
QGP 欄位是什麼意思？▼

GP（Gross Profit，毛利率）是獎金計算的附加條件，填入小數比例（例如 0.3 代表 30%）。不需要時可以留空。

2. Sales ID Config（Sales ID 設定）
QJan ~ Dec 欄位要填什麼？▼

代表該 Sales ID 在該月份是否啟用（isActive）：

  • 1（或任何非空白值）＝ 啟用，該月業績計入
  • 0 或留空 ＝ 停用，該月不計入
常見用法全年啟用：全填 1；下半年啟用：Jul~Dec 填 1，Jan~Jun 填 0。
Q一位業務員有多個 Sales ID，要怎麼設定？▼

每個 Sales ID 各填一行，Email 與 Group Name 相同（或都留空）。

EmailGroup NameSales IDJanFeb...Dec
john@co.com（空白）S00111...1
john@co.com（空白）S00211...1

範例7 月換 Sales ID：

john@co.comS001（舊）111111000000
john@co.comS999（新）000000111111
QIND/NOACC 和 LEADER 匯入 Sales ID Config 的行為有什麼差異？▼

兩種模式的增刪語意不同，請特別注意 LEADER 的「Full-truth」行為：

Commission Type情況系統動作
IND / NOACC
Delta 模式		 該 Email 出現，至少一月 = 1INSERT 或 UPDATE
該 Email 出現，所有月份空白DELETE 該 Sales_Id
該 Email 未出現在 Sheet不動（Job 維護基底）

該 Email 出現，所有月份空白IGNORE（忽略）

IND/NOACC 移除 Sales ID填一行該 Sales ID，Jan~Dec 全部留空，上傳後系統會 DELETE 該筆。
QRS 類型的業務員需要設定 Sales ID Config 嗎？▼

不需要。RS 類型業務員不使用 Sales ID，業績計算依 RS Sheet 設定的報表維度（Region/Entity/Sector/Prod_Group）從報表系統拉取。

3. Mapping（觀看權限）
QMapping 是什麼用途？▼

設定誰可以看到誰的業績資料（觀看權限），與管理階層無關。

  • Email：觀看者（要開放觀看權限的人）
  • Sales Email：被觀看的業務員 Email
範例主管 A 想查看業務員 B 和 C 的業績：
→ 填兩行：Email = A，Sales Email 分別填 B、C
Q主管要看所有組員的業績，要怎麼設定？▼

每位組員填一行，Email 欄填主管，Sales Email 欄填各組員 Email。

Email（觀看者）Sales Email（被觀看者）
manager@co.comsales1@co.com
manager@co.comsales2@co.com
manager@co.comsales3@co.com
Q業務員離職或轉組，原有的觀看權限要怎麼移除？▼

系統匯入只做 UPSERT，不會自動移除舊記錄。移除方式：

  • 逐筆刪除（推薦）：至 Data View → Mapping Tab，找到該筆記錄點 Delete，即時生效。
  • 整批重傳：在 Upload History 中刪除整批上傳記錄，再重新上傳不含該筆的 Excel。
Q非主管（例如 PM 或跨部門同事）也能設定觀看權限嗎？▼

可以。Mapping 不限定管理關係，任何需要觀看特定業務員業績的人都可以在此設定。

4. RS（Revenue / Quota 篩選條件）
QRS Sheet 是用來設定什麼的？▼

RS（Report Source）設定系統在計算 RS 類型業務員的獎金時，要從哪個報表、哪些維度條件下抓取 Revenue 和 Quota。每一行代表一組篩選條件組合。

注意RS Sheet 不包含 Site 欄位；Region 欄位已涵蓋地區資訊。
QReport 欄位可以填什麼？大小寫有影響嗎？▼

系統支援別名對應，不分大小寫，上傳後自動正規化為標準值：

Product / Sales by Product / SalesByProductSalesByProductSALES_PRODUCT
My Sales Force / MySalesForceMySalesForceSALES_FORCE
建議直接填標準值（SalesByRegion、SalesByProduct、MySalesForce）最清楚，別名主要用於舊格式相容。

QRS 的 Jan~Dec 和 Sales ID Config 的 Jan~Dec 有什麼不同？▼
  • Sales ID Config 的 Jan~Dec：控制該 Sales ID 在哪些月份的業績納入計算。
  • RS 的 Jan~Dec：控制這組 RS 篩選條件在哪些月份有效（isActive）。

兩者都是 isActive 旗標，概念相同，但作用對象不同。

5. Group Name（多重計算方式）
QGroup Name 是什麼？一定要填嗎？▼

Group Name 是用來支援同一位業務員有多種獎金計算方式的關聯鍵。

  • 只有一種計算方式 → 留空即可
  • 有兩種以上計算方式 → 填入自訂名稱區分（例如 CR9、CR4）
關聯方式Commission Rate、Sales ID Config、RS 三張 Sheet 透過 Email + Group Name 做對應，Group Name 相同的資料視為同一組計算邏輯。
Q業務員負責 5 個 Sales ID，其中 2 個 CR% 9%，另外 3 個 CR% 4%，要怎麼設定？▼

Commission Rate sheet（填兩行）：

EmailGroup NameTypeThresholdStd CR%
john@co.comCR9LEADER0.80.09
john@co.comCR4LEADER0.60.04

Sales ID Config sheet（依 Group Name 分配）：

EmailGroup NameSales IDJan~Dec
john@co.comCR9S001全填 1
john@co.comCR9S002全填 1
john@co.comCR4S003全填 1
john@co.comCR4S004全填 1
john@co.comCR4S005全填 1
QGroup Name 命名格式有限制嗎？▼

文字欄位，長度上限 50 字元，可自由命名。建議使用簡短易辨識的英文：

  • 依費率：CR9、CR4
  • 依區域：TW、JP
  • 依產品線：ProductA、ProductB
注意Commission Rate、Sales ID Config、RS 三張 Sheet 中填入的 Group Name 必須完全一致（區分大小寫），否則系統無法正確對應。
Q原本只有一種計算方式，現在要拆成兩種，需要怎麼調整？▼
  1. 在 Commission Rate Sheet 新增第二行，填入新的 Group Name 和費率。
  2. 在 Sales ID Config 中，將原本空白 Group Name 的行改為指定 Group Name，並新增第二組 Sales ID 行。
  3. 若有 RS 設定，同樣依 Group Name 拆分兩組。
  4. 重新上傳，系統以 Email + Group Name 為 Key 更新資料。
注意若原本 Group Name 為空白，上傳新資料時，空白 Group Name 的舊資料不會自動刪除。若要完整切換，請至 Data View 手動刪除舊設定，或洽系統管理員。
