1. 系統概述

TCP Platform 是 TCP 後台管理系統，以功能 Hub 頁為入口，各功能以獨立 Page 呈現。

路由說明
/Admin/TcpPlatformHub 首頁（功能卡片導覽）
/Admin/TcpPlatform/Upload業務員設定檔上傳功能
/Admin/TcpPlatform/OrgHierarchy組織架構管理（樹狀結構）

4. API 端點（TcpUpload）

Method路由說明
GET/api/TcpUpload/GetSites?yearId=取得 TCP Site 清單
POST/api/TcpUpload/ParsePreview解析 Excel，回傳預覽（不寫 DB）
POST/api/TcpUpload/Import直接上傳寫入 DB
POST/api/TcpUpload/ImportFromPreview由預覽資料寫入 DB
GET/api/TcpUpload/GetLogs?yearId=&site=查詢上傳記錄
DELETE/api/TcpUpload/DeleteLog/{logId}?yearId=刪除上傳記錄及關聯資料

5. 資料庫

TcpUpload 使用資料表（MFG DB，依年份切換）：TCP_Upload_Log、TCP_Sales_TCR_Rate、TCP_Sales_TCR_Manager、TCP_Sales_TCR_Mapping、TCP_Sales_TCR_Change、TCP_Sales_RS。連線：IMFGDatabaseHelper.GetDbConnection(yearId)（傳 4 位數年份，如 2026 → MFG2026Connection）。

6. 新增功能的標準流程

Step 1 後端：TcpPlatformController 新增 Action（回傳 View）→ 需要 API 則在 Controllers/Api/ 新增 → 建立 Service/Repository/DataModel（各自 Tcp/ 資料夾）→ ServiceRegistration.cs 註冊 DI。

Step 2 前端：Views/TcpPlatform/ 新增 .cshtml；wwwroot/js/TcpPlatform/ 新增 .js。

Step 3 Hub：Index.cshtml 新增功能卡片，將 Coming Soon 改為實際連結。

Step 4 權限：依第 3 節在管理介面新增 Page 並設定 Role。
