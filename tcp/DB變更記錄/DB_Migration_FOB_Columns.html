TCP_Sales_TCR_Rate — 移除 FOB 欄位

移除未被任何 Stored Procedure 參照的 FOB 系列欄位
執行對象MFG2025、MFG2026（及其他年份別 DB）
類型欄位移除
來源03_DB_Migration / DB_Migration_FOB_Columns.sql
背景：FOB 欄位（X_Rate_FOB、Y_Rate_FOB、X_Rate_FOB_Jan～Dec）已不被任何 Stored Procedure 參照，且已從 DataModel、Repository、Service 各層移除，故一併從資料表清掉。
移除 FOB 系列欄位
自 TCP_Sales_TCR_Rate 移除 X_Rate_FOB、Y_Rate_FOB 及 X_Rate_FOB_Jan～Dec 共 14 個欄位。
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN Y_Rate_FOB;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Jan;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Feb;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Mar;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Apr;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_May;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Jun;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Jul;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Aug;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Sep;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Oct;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Nov;
ALTER TABLE TCP_Sales_TCR_Rate DROP COLUMN X_Rate_FOB_Dec;
