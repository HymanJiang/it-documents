View：vw_TCP_Quota_By_SalesId

供 DataView Overview 查詢各 Sales ID 年度 Quota
目標 Serveraclemanager-db.advantech.corp（eManagerDB）
目標 DBMFG26（及各年份 MFG DB，需逐一執行）
日期2026-06-05
來源03_DB_Migration / DB_View_Quota_By_SalesId.sql
資料來源：Linked Server [ACLSTNR11.advantech.corp].MFG26.dbo.Quota_Sales_Force，只取 Tran_type = 'General'，依 Sales_id / Year_id / Currency 彙總各月份與 Total。
View 定義
每個年份別的 MFG DB 需逐一執行（USE [MFGxx]）。
USE [MFG26]
GO

IF EXISTS (SELECT 1 FROM sys.views WHERE name = 'vw_TCP_Quota_By_SalesId')
    DROP VIEW vw_TCP_Quota_By_SalesId;
GO

CREATE VIEW vw_TCP_Quota_By_SalesId AS
SELECT
    Sales_id   AS SalesId,
    Year_id    AS YearId,
    Currency,
    SUM(Jan) AS Jan, SUM(Feb) AS Feb, SUM(Mar) AS Mar, SUM(Apr) AS Apr,
    SUM(May) AS May, SUM(Jun) AS Jun, SUM(Jul) AS Jul, SUM(Aug) AS Aug,
    SUM(Sep) AS Sep, SUM(Oct) AS Oct, SUM(Nov) AS Nov, SUM([Dec]) AS [Dec],
    SUM(Total) AS Total
FROM [ACLSTNR11.advantech.corp].[MFG26].[dbo].[Quota_Sales_Force]
WHERE Tran_type = 'General'
GROUP BY Sales_id, Year_id, Currency;
GO
