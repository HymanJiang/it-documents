TCP 改版 / DB 變更記錄

幣別欄位 Migration

為 Site 與費率表新增 ReportCurrency / PayCurrency / LocalCurrency
執行對象MFG2025、MFG2026（及各年份 DB）
日期2026-06-05
類型欄位新增
來源03_DB_Migration / DB_Migration_Currency.sql
1. TCP_Site：新增 LocalCurrency
IF NOT EXISTS (
    SELECT 1 FROM sys.columns
    WHERE object_id = OBJECT_ID('TCP_Site') AND name = 'LocalCurrency'
)
BEGIN
    ALTER TABLE TCP_Site ADD LocalCurrency NVARCHAR(10) NULL;
END
GO
2. TCP_Sales_TCR_Rate：新增 ReportCurrency、PayCurrency
ALTER TABLE TCP_Sales_TCR_Rate ADD ReportCurrency NVARCHAR(10) NULL;  -- 若不存在
ALTER TABLE TCP_Sales_TCR_Rate ADD PayCurrency    NVARCHAR(10) NULL;  -- 若不存在
GO
3. TCP_Sales_TCR_Rate_History：同步新增欄位
History 表同步補上 ReportCurrency、PayCurrency，與主表結構一致。
ALTER TABLE TCP_Sales_TCR_Rate_History ADD ReportCurrency NVARCHAR(10) NULL;
ALTER TABLE TCP_Sales_TCR_Rate_History ADD PayCurrency    NVARCHAR(10) NULL;
GO
