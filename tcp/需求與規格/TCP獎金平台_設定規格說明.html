TCP 獎金平台 — 設定規格說明

版本v1.0（2026-05-12）
說明業務員獎金設定的完整規格，涵蓋身分設定與獎金計算設定兩個部分

業務員的獎金設定分為兩個獨立部分，各有不同的設定時機與操作者：

Part 1 — 身分設定 Part 2 — 獎金計算設定

影響範圍 僅影響 Over Quota 加成計算 影響所有獎金計算邏輯
設定來源 Role Permission 系統（或本平台） 本平台，由設定同仁操作
設定頻率 人員建立時，異動時才改 每年一次，年中可異動
1
身分設定
決定業務員的角色，唯一用途是計算 Over Quota 加成比率

設定欄位

欄位選項說明
角色 一般業務 / 主管 決定超額獎金的加成比率與全年所得上限係數（TCP × 5 或 × 3）

Over Quota 加成對照

角色 Over Quota 100–120% Over Quota >120% 全年所得上限
一般業務 +1% +0.5% TCP × 5
主管 +0.5% +0.3% TCP × 3
重要：角色設定僅影響 Over Quota 加成，與下方 Part 2 的計算方式（IND / Leader / RS / NoAcc）無直接關聯。 一位設定為「主管」角色的業務員，其計算方式可以是 IND，也可以是 LEADER，兩者獨立設定。
身分設定可從 Role Permission 系統同步帶入，無需在本平台重複設定。 若本平台需要提供設定入口，應以 Role Permission 為主，本平台顯示為唯讀並標示來源。
2
獎金計算設定
設定 CR% 與計算方式，依選擇的方式顯示對應的設定介面

共同設定欄位

欄位說明備註
CR%（Commission Rate） 獎金計算的費率，由負責人提供，系統不自動推算 預設全年相同，可依月份個別設定；每年設定一次，年中可異動
匯率（選填） 若業績以外幣計算，可填入固定匯率，獎金計算時套用此匯率換算為本地幣別。
欄位組成：幣別下拉（USD / EUR / …）+ 匯率數值輸入框。
公式：出貨（外幣）× CR% × 匯率 → 本地幣別獎金 		選填；未填則視為無匯率換算，以原幣別直接計算。
填入後報表業績欄位固定顯示外幣，不換算。
計算方式 IND / Leader / RS / NoAcc 四選一 決定業績來源與計算邏輯，選擇後顯示對應設定介面

四種計算方式概覽

IND
個人業績
以本人 Sales ID 的出貨業績計算
Leader
主管業績
加總指定 Sales ID 的業績
RS
區域 / 產品別業績
依報表來源篩選計算
NoAcc

依客戶新舊分段計算 CR

IND / NoAcc / Leader — Sales ID 設定

三種計算方式共用同一套 Sales ID 設定介面，差異在於 ID 的來源與預設行為：

計算方式 Sales ID 來源 預設行為
IND 系統帶出該業務員在公司規範下的所有 ID 全部帶入，預設 1–12 月全年負責
NoAcc 系統帶出該業務員在公司規範下的所有 ID 全部帶入，預設 1–12 月全年負責
Leader 系統帶出該業務員在公司規範下的所有 ID 全部帶入，預設 1–12 月全年負責；可移除或額外新增其他 ID

欄位規格
Sales ID 下拉選單，帶出所有可選的 Sales ID；支援模糊查詢（輸入部分 ID 或名稱即可篩選）
負責月份 12 個 Checkbox（1月 ～ 12月），可多選；預設全勾選（全年負責）
取消勾選代表該 Sales ID 在該月份不計入業績

清單操作

  • 新增：點「新增 Sales ID」，從下拉選單選擇（支援模糊查詢），設定負責月份後加入清單
  • 移除：點該列的移除按鈕，從清單中刪除
  • 全選 / 全取消：月份 Checkbox 列上方提供快捷按鈕

RS — 區域 / 產品別設定

RS 不使用 Sales ID，改以報表為業績來源。 設定時先選擇參考報表，系統依報表類型帶出對應的篩選器。

步驟 1 — 選擇參考報表

從以下報表中選擇一個作為業績來源（可多選）：

報表名稱業績計算依據篩選器
SalesByRegion 依業務區域加總出貨業績 區域、客戶
SalesByProduct 依產品線 / 產品別加總出貨業績 產品線、產品編號
MySalesForce 依業務員組合加總出貨業績 業務員清單
選擇多份報表時，系統將各報表計算結果加總為最終業績。
步驟 2 — 設定篩選條件（依所選報表動態帶出）

選定報表後，系統依該報表的結構帶出對應篩選欄位。 各篩選欄位均為多選，預設空值（不限定）。 篩選選項的內容依共用架構（報表系統）帶入，實際可選項目以報表系統定義為準。

報表帶出的篩選欄位空值代表
SalesByRegion 區域（多選）、客戶（多選） 不限定，計入該報表所有資料
SalesByProduct 產品線（多選）、產品編號（多選） 不限定，計入該報表所有資料
MySalesForce 業務員清單（多選） 不限定，計入該報表所有資料
篩選欄位為空值時代表「不限定」，系統計入該報表下的所有資料。 若要縮小範圍，才需要選取特定條件。
步驟 3 — 設定負責月份

以 Checkbox 勾選負責月份，可多選；預設全年（1–12 月）全勾選。

Quota 預覽與儲存

完成計算方式與內容設定後，頁面下方自動帶出對應的 Quota 預覽， 讓設定同仁確認數字正確後再儲存。

Quota 預覽規格
計算方式Quota 資料來源帶出內容
IND / NoAcc / Leader 對應 Sales ID 的資料表 依已選取的 Sales ID 與負責月份，撈取對應業績數值
RS 對應報表的數值 依已選取的報表、篩選條件與負責月份，撈取對應報表數值
Quota 預覽為唯讀顯示，供確認用，不可在此直接修改。 若數字與預期不符，應回到上方調整 Sales ID 或篩選條件後，預覽會自動更新。
儲存按鈕
  • 儲存按鈕位於頁面最下方，Quota 預覽確認後才點擊
  • 儲存前系統驗證必填欄位（CR%、計算方式）是否已填寫
  • 儲存成功後回到設定總覽頁
