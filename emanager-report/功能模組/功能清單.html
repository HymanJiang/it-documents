3 Level 決定邏輯

初次載入（無 MeasuresValue）

isDefaultLevel行為
true使用 vw_Report_Level_Permission.DefaultLevel；無權限記錄 → Level = 0（無存取權）
false固定從 Level = 1 開始

使用者有選擇（有 MeasuresValue）

1. 依序檢查各層，找到第一個值為 "ALL" 的層 → 使用該層
2. 全部都非 "ALL" → 使用 MaxLevel
3. 套用 Level 權限：從授權清單找 ≥ 當前 Level 的最小值

⚠
Level = 0 時直接回傳空報表，不執行後續 Dimensions / Measures / KPI / 資料查詢。

4 三層權限控管

Layer 1
Level

可見層級控管

資料來源：vw_Report_Level_Permission
輸出：DefaultLevel（預設顯示層）、RequiredPermissionLevelsList（允許切換的層清單）

Layer 2
Measure

可見組織單位控管

資料來源：vw_Report_Measures_Permission
Report_Level.hasPermission = 1 才啟用該層過濾
包含 "ALL" → 全部顯示；無 "ALL" → 只顯示授權名稱；無記錄 → 全部顯示

Layer 3
KPI

可見 KPI 欄位控管

資料來源：Report_Measures_KPIs_Permission（需設 Permission = 1）
支援通用規則（Email 空）與個人規則（Email 有值）
進階：CheckLevel + LastLevelMeasures 可依「前指定層的選擇值」動態決定顯示

KPI 權限判斷流程

條件結果
KPI.Permission = false永遠顯示
Permission = true，有任一筆 LastLevelMeasures 為空顯示（不限制）
Permission = true，所有筆 LastLevelMeasures 都有值逐筆比對 checkLevel 選擇值；符合 → 顯示；全不符合 → 隱藏；使用者尚未選擇 → 預設顯示

9 KPI 名稱年份動態轉換

Service 層在 GetReportKPI() 中依 reportFilter.Year 建立轉換字典，每次查詢時執行：

原始 KPI 名稱轉換後（以 2025 年為例）
LastYear Actual2024 Actual
CurrentYear Quota2025 Quota
CurrentYear Achv.2025 Achv.
CurrentYear Backlog2025 Backlog
LastYear Digital Actual %2024 Digital Actual %
CurrentYear Digital Actual %2025 Digital Actual %
2025Shipment2025 Achv.
2024Shipment2024 Actual
ℹ
DisplayName 同步規則：若 DB 中 DisplayName == Name，DisplayName 跟著 Name 一起轉換年份。若兩者不同，DisplayName 保持固定，只有 Name 做資料比對轉換。

10 Non-Breaking Space 字元清理

KPI 名稱在進行 Dictionary 比對前，TransformKPIName() 先執行 normalize：

originalName.Replace(' ', ' ').Trim()

⚠
字元碼 160（Unicode Non-Breaking Space）與一般空白外觀相同，但 Dictionary lookup 會失敗。DB 中若有此字元，年份轉換將不會套用，KPI 名稱維持原始字串。

11 FilterColumn "null" 清理

GetReportSources() 建立 FilterColumn 後自動執行兩項清理：

清理項目處理方式
值為字串 "null"從 filterColumnValue 移除，避免傳入 DB 的 IN 條件
包含 "all"（不分大小寫）整個 filterColumnValue 簡化為 ["ALL"]

12 零值 Measures 過濾

取得資料後，特定報表過濾關鍵 KPI 值為 0 的 Measures，避免顯示空白行。非當前 Level 的 Measures 不受影響。

觸發條件過濾 KPI過濾維度
Name = "Sales Performance"{Year} Achv.Year Total
ReportCode = "HC Dashboard"RevenueYTM
ReportCode = "CRM"AchivementYear Total

13 RedirectUrl 佔位符替換

Report_Basic.RedirectText 和 RedirectUrl 同時有值時，顯示導向按鈕。渲染前 NewReportStructure() 自動替換 URL 中的佔位符：

佔位符替換內容
{Email}當前使用者（含模擬）的 Email
{EZTicketId}使用者的 EZTicket SSO Token
