1. 背景

uSP_MSUScorecard2026_N_Data_TW 是獨立執行的預存程序（主程序 uSP_MSUScorecard2026 並未呼叫它），手動 EXEC 後以 SELECT ... PIVOT 直接回傳 ATMC（台灣）各廠的財務 KPI（MOPEX、Hourly Rate、閒置成本等）。

初版檢核（3 月）共 17 項 N（計算錯誤）+ 12 項未計算。本次修正後，凡屬程式／對照表可解者皆已修正並驗收通過，餘 3 項屬「業務定義」需財務拍板（見第 5 節）。

2. 預存程序（SP）變更明細

以下為邏輯說明與關鍵 SQL 前後對照。實際檔案已套用，編碼維持 UTF-16 LE。

E1當月成倉費用 — 廠別歸屬錯誤

症狀：掛在 ATMC total，應為 ATMC-林口發貨倉（VK04）。

-- 前
'ATMC total' AS [PLANT],
-- 後
N'ATMC-林口發貨倉' AS [PLANT],

E2ATMC-LA MOPEX(K) — 993 科目排除規則

需求：「993* 全排，只加回 993002、993019」。

-- 前
WHERE [CostElement] NOT IN ('993020','993021')
-- 後
WHERE ([CostElement] NOT LIKE '993%' OR [CostElement] IN ('993002','993019'))

E3MOPEX-SMT / Labor / ES(K) — 重複計算 2 倍（重點）

症狀：MOPEX_SpecialConfig 以 Exception <> CostElement 做 JOIN，單一 cost center 有多筆排除碼時，金額被乘上排除碼筆數（SMT/Labor 約 2 倍）。

修正：改為「存在即排除」的 NOT EXISTS，並新增 MOPEX_SpecialMap（cost center→指標 去重對照）。

[MOPEX_SpecialMap] AS (
    SELECT DISTINCT [PLANT],[DESCRIPTION],[Costcenter] FROM [MOPEX_SpecialConfig]
),
[MOPEX_Special] AS (
    SELECT A.[YEAR_ID],A.[MONTH_ID],M.[PLANT],M.[DESCRIPTION],SUM(A.[AMOUNT]) AS [AMOUNT]
    FROM [MOPEX_Data] A
    INNER JOIN [MOPEX_SpecialMap] M ON M.[Costcenter] = A.[Costcenter]
    WHERE A.[MONTH_ID] <= @Month
      AND NOT EXISTS (
          SELECT 1 FROM [MOPEX_SpecialConfig] X
          WHERE X.[Costcenter] = A.[Costcenter] AND X.[Exception] = A.[CostElement])
    GROUP BY A.[YEAR_ID],A.[MONTH_ID],M.[PLANT],M.[DESCRIPTION]
)

E5'Hourly Rate - Labor(Standard) — 應取平均

來源 kp27 每個 cost center 有 2 筆，先前誤改 AVG 會把所有標準率砍半；正解：維持 SUM，僅 Labor 的 LH12/13/14 各除以 cost center 數（3）。

-- HourlyRateItem 第一段 AMOUNT 改為：
CASE WHEN [Costcenter] IN ('LH12','LH13','LH14') THEN [AMOUNT] * 60 / 10000 / 3
     ELSE [AMOUNT] * 60 / 10000 END AS [AMOUNT]
-- 外層彙總維持 SUM([AMOUNT])

E6ATMC-CTOS 閒置成本(%) — 量級錯誤

-- 前（得 ~ -2.9e-7）
ISNULL(A.[AMOUNT],0) / (ISNULL(C.[AMOUNT],0) * ISNULL(D.[AMOUNT],0) ) / 1000 AS [AMOUNT]
-- 後（得 ~ -0.29）
ISNULL(A.[AMOUNT],0) * 1000 / (ISNULL(C.[AMOUNT],0) * ISNULL(D.[AMOUNT],0) ) AS [AMOUNT]

E7Hourly Rate - 人力（ATMC total）— 分母用錯欄位

-- 前（誤除以 PG Charge）
(A.[AMOUNT] - B.[AMOUNT]) / B.[AMOUNT] * 1000 AS [AMOUNT]
-- 後（除以工時 C）
(A.[AMOUNT] - B.[AMOUNT]) / C.[AMOUNT] * 1000 AS [AMOUNT]

E8ATMC-LA 閒置成本(K)-SMT/Labor — 後綴遺失 + 乘除錯

-- 描述補上 -SMT/-Labor 區分
N'閒置成本(K) - ' + A.[DESCRIPTION] AS [DESCRIPTION],
-- 工時×標準率（前為 B/C，後為 B*C）
ELSE A.[AMOUNT] - (B.[AMOUNT]*C.[AMOUNT]) / 1000

E9名稱字串不一致（造成多項「未計算」）

取用端字串對齊產出端（以對外輸出名稱為準）：

取用端（前）改為（後）
'MOPEX - SMT(K)','MOPEX - Labor(K)''MOPEX-SMT(K)','MOPEX-Labor(K)'
N'SAP產出工時 - SMT(Hr)' 等N'SAP產出工時 -SMT(Hr)' 等
'Hourly Rate - SMT(Standard)''Hourly Rate-SMT(Standard)'

E10BCM 委外加工費 — OR/AND 優先序

-- 後（加括號，使 No / 廠別過濾正確套用到兩個 LIKE）
WHERE ([Name] LIKE N'%委外加工費-BCM%'
    OR [Name] LIKE N'%委外加工費-板階外包%')
    AND [No] = 1
    AND [eMgrShowName] = 'ATMC-LA'

E11ATMC-LA Hourly Rate-SMT/Labor — 漏乘 1000

-- 前
A.[AMOUNT] / B.[AMOUNT] AS [AMOUNT]
-- 後
A.[AMOUNT] * 1000 / B.[AMOUNT] AS [AMOUNT]

E12ATMC-LA 閒置成本(K)-SMT/Labor — JOIN 漏配對條件

症狀：MOPEX 與 WorkHour / Hourly_Rate 的 JOIN 僅 年/月/廠，缺 DESCRIPTION，造成 SMT×Labor 交叉（出現 -14 萬等離譜值）。

-- 兩個 LEFT JOIN 各補：
AND B.[DESCRIPTION] = A.[DESCRIPTION]
AND C.[DESCRIPTION] = A.[DESCRIPTION]

E13 + E4ATMC-泛System Hourly Rate-Assembly — 重複列 + 漏乘 1000

症狀：對照表 No=2 對泛System 有 MH10、MH14 兩筆都對到 Phase_3='SAP產出工時(H)'；SP 以 INNER JOIN 把 Temp 內「工時總額」那一筆複製成兩列，PIVOT SUM 後變 2 倍（1.65）。

修正：INNER JOIN → EXISTS（只做存在性過濾、不複製），並補泛System 的 ×1000。

[WorkHour] AS (
    SELECT A.[YEAR_ID],[MONTH_ID],[PLANT],[DESCRIPTION],[AMOUNT]
    FROM [Temp_SCORECARD_MSU_N_Data] A
    WHERE A.[YEAR_ID] = @Year
    AND [PLANT] IN (N'ATMC-泛System','ATMC-CTOS')
    AND EXISTS (
        SELECT 1 FROM [SCORECARD_MSU_N_HierarchyMapping] B
        WHERE B.[eMgrShowName] = A.[PLANT]
        AND B.[Phase_3] = A.[DESCRIPTION]
        AND B.[Year_ID] = A.[YEAR_ID]
        AND B.[No] = 2)
)
-- 泛System 分支：ELSE A.[AMOUNT] * 1000 / C.[AMOUNT]

3. 對照表（HierarchyMapping）變更

LG10 在 No=2（工時）被誤標為 ES SMT，應為 ES Labor：

USE [Global_Fin];
UPDATE [SCORECARD_MSU_N_HierarchyMapping]
SET [Phase_2] = 'ES Labor(Hr)'
WHERE [Year_ID]=2026 AND [No]=2 AND [Phase_1]='LG10';   -- 更新筆數 = 1
改對照表後不需重部署 SP，直接 EXEC 即可（SP 每次重撈對照表）。

6. 部署備忘（避免重蹈覆轍）

  • SP 檔為 UTF-16 LE + BOM；用程式批次改檔需以二進位寫入，避免換行被重複轉成 \r\r\n 導致編輯器「格式錯誤」。
  • 在 SSMS 改 SP 後務必：重新開檔（避免舊分頁覆蓋）→ F5（ALTER 更新 DB 程序）→ 另外 EXEC 才會回結果。
  • 驗證 DB 是否為新版：
    OBJECT_DEFINITION(OBJECT_ID('dbo.uSP_MSUScorecard2026_N_Data_TW')) LIKE '%MOPEX_SpecialMap%'
