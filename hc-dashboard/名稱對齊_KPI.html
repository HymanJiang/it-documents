HC Dashboard KPI 名稱對齊 worksheet

標準 = Notion 2026/6/8。對齊三處：SP 寫入 DSB_HC_ReportData.KPI = 框架 Report_Measures_KPIs.Name（View 用 Name 比對資料）。 DisplayName 為前端顯示文字，可與 Name 不同（用來讓重複的「- IDL/- DL」共用顯示名、用 Name 區分資料）。

命名正規化原則（本 worksheet 採用）： 1. 前綴破折號只放 DisplayName，Name 不帶「- 」。理由：現行 SP 寫 - IDL 匯出 Excel 被當公式 → #NAME?。 2. 重複的「- IDL / - DL」用 Name 區分：IDL/DL（Total HC 拆解）、New Hires IDL/New Hires DL、Turnover IDL/Turnover DL、Turnover % IDL/Turnover % DL。 3. HC/ Budget 不是 KPI 列 → 沿用框架 SpecialKPI H/C Budget（不進 Report_Measures_KPIs）。 4. Last Year HC（2025 Dec）沿用框架 SpecialKPI（待確認新版是否改成維度欄，見文末）。

來源/計算：Leaf=來源欄位、Scorecard=Revenue 來源、計算=SP 衍生。 YTM「-」：該 KPI 在 YTM 欄顯示破折號（FutureMonthsAdjustment/SpecialRule 機制）。

上色機制注意（Gap 2）

Turnover % 要雙門檻（<5% 綠、>10% 紅），但框架現行 CompareCategory/CompareType/Compare/CompareStyle 一個 KPI 只支援單一門檻。需擴成多條規則，或先只標一個門檻。→ 列入框架小改清單。
