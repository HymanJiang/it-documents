UI 調整：SBU/RBU 的 Region/KPI 列標題欄寬（commit 9fe84d1）

  • 範圍：只動 HCFormatReport.cshtml（SBU/RBU 專屬 View）內嵌 <style>/script；共用 ClassicReport.cshtml、eManagerReport.css 零修改，Operation/COE 與其他報表不受影響。
  • 問題：長 Region 名稱（如 Intercon & S. Asia Pacific w/o HQDC）被切；改自動寬度後又發現文字右側留白過多。
  • 根因：右側留白來自共用 .DataBox table { width:100% }——table-layout:auto 下自然內容寬度 < 容器時，多餘寬度被分攤到各欄，Region 欄 td(auto) 分到的寬度在靠左名稱右側成為空白。
  • 修正：
  • .Measures div { width:max-content } 覆寫共用固定 150px → 欄寬依名稱、不再切字。
  • .Measures、.Kpi 加 width:1%（搭配既有 nowrap）→ 兩個列標題欄收到內容寬度，多餘寬度改分給月份欄，消除右側留白。
  • .Measures 右 padding 10px→3px。
  • 小段 script：依實際 Region 欄寬動態設定 KPI 凍結欄的 sticky left，resize 重算、<=1600px（共用 CSS 取消 sticky）清掉位移。
  • 驗收：CSS/View 改動，部署後務必 Ctrl+F5。

五、Turnover% 公式說明與 1 月跨年修正

  • 公式：當月 Turnover % = 當月 # of Turnover / ((當月 Total HC + 前月 Total HC) / 2)，逐月（1~12）、每 measure 各算、不可加總。Operation IDL/DL 版分母用各自 IDL/DL HC。值存小數、框架以 Percentage 轉 %、>10% 紅（雙色待做）。
  • 1 月修正（使用者確認）：原本 1 月找不到前月→退回用當月 HC；改為 1 月前月＝去年 12 月 HC（#Stage 含所有年度月資料）。改 sp_DSB_HC_New.sql Stage5b/5c 三處 pm join：(同年 Dim-1) OR (去年 Dim=12 且 t.Dim=1)；去年也無資料時 ISNULL 退回當月。需重跑 SP 套用（只影響 1 月值）。
