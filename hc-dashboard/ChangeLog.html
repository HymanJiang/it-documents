UI 調整：SBU/RBU 的 Region/KPI 列標題欄寬（commit 9fe84d1）

  • 範圍：只動 HCFormatReport.cshtml（SBU/RBU 專屬 View）內嵌 <style>/script；共用 ClassicReport.cshtml、eManagerReport.css 零修改，Operation/COE 與其他報表不受影響。
  • 問題：長 Region 名稱（如 Intercon & S. Asia Pacific w/o HQDC）被切；改自動寬度後又發現文字右側留白過多。
  • 根因：右側留白來自共用 .DataBox table { width:100% }——table-layout:auto 下自然內容寬度 < 容器時，多餘寬度被分攤到各欄，Region 欄 td(auto) 分到的寬度在靠左名稱右側成為空白。
  • 修正：
  • .Measures div { width:max-content } 覆寫共用固定 150px → 欄寬依名稱、不再切字。
  • .Measures、.Kpi 加 width:1%（搭配既有 nowrap）→ 兩個列標題欄收到內容寬度，多餘寬度改分給月份欄，消除右側留白。
  • .Measures 右 padding 10px→3px。
  • 小段 script：依實際 Region 欄寬動態設定 KPI 凍結欄的 sticky left，resize 重算、<=1600px（共用 CSS 取消 sticky）清掉位移。
  • 驗收：CSS/View 改動，部署後務必 Ctrl+F5。

一、資料層目視驗收與修正

  • PK 衝突（SBU,USD,2026,Total HC,iSystem-iMs,Jun 重複）→ 來源 rv_hr_hc_dashboard 對同一 PG／月份有多列（子單位明細），應加總。修正：sp_DSB_HC_New.sql 四個葉節點（SBU/RBU/Operation/COE）＋兩個 Revenue（SBU/RBU）的 INSERT 加上 SUM(...) + GROUP BY（粒度對齊 PK）。
  • Turnover% 畫面沒出 → 純瀏覽器頁面快取；框架不快取 KPI，設定/資料/程式三邊皆正確。驗收時改完務必 Ctrl+F5。
  • SBU 2025 資料缺（致「前一年 Dec」欄、Last Year HC 抓不到）→ 當初新 SP @Year=2025 在 SBU 命名修正前跑/沒跑成。解法：以現行 config 補跑 EXEC sp_DSB_HC_New @Year=2025。

二、框架修正：RBU HQDC 列不顯示

  • 根因：ReportStructureService.cs 的 switch(reportBasic.ReportCode) 有 case "HC Dashboard"，用「Revenue YTM <> 0」過濾 measures（本為 CRM/Sales Performance 設計）。HQDC ShowRevenue=0 → 無 Revenue → 被誤刪；CIS/AURES 同理；且 SBU 補完 Revenue 後也會誤刪零值列。
  • 修正：移除該 case "HC Dashboard"。HC 列顯示改由 DSB_HC_Hierarchy.IsActive + vw 決定。CRM/Sales/OSF 不受影響。

三、Format 下拉（方法 B，SBU/RBU）

  • 規格（Notion）：SBU/RBU 各三個 Format（HC Management / Turnover / Revenue per Employee），各顯示不同 KPI 子集；Employee link 只在 HC Management 顯示。HC/Budget 為 SpecialKPI，三 Format 恆顯示。
  • DB：新表 Report_Measures_KPIs_Format（EMGRV2），腳本 SQL Server\Table\framework_HC_KPIFormat.sql。Sort 編碼 HC Mgmt 1../Turnover 11../RevPerEmp 21..。
  • C#（全加法）：ReportFilter+Format、Report+AvailableFormats、新 model Report_Measures_KPIs_Format、Repository GetReport_Measures_KPIs_Format、Service GetReport 設可用 Format/預設值＋GetReportKPI 末端 if(map.Any()) 閘門過濾排序。
  • 路由：HomeController.NewReportStructure 依 Report.AvailableFormats.Any() 路由到新 View（不改 Report_Basic.ReportType）。Operation/COE 無 Format → 走原 ClassicReport。

五、Turnover% 公式說明與 1 月跨年修正

  • 公式：當月 Turnover % = 當月 # of Turnover / ((當月 Total HC + 前月 Total HC) / 2)，逐月（1~12）、每 measure 各算、不可加總。Operation IDL/DL 版分母用各自 IDL/DL HC。值存小數、框架以 Percentage 轉 %、>10% 紅（雙色待做）。
  • 1 月修正（使用者確認）：原本 1 月找不到前月→退回用當月 HC；改為 1 月前月＝去年 12 月 HC（#Stage 含所有年度月資料）。改 sp_DSB_HC_New.sql Stage5b/5c 三處 pm join：(同年 Dim-1) OR (去年 Dim=12 且 t.Dim=1)；去年也無資料時 ISNULL 退回當月。需重跑 SP 套用（只影響 1 月值）。
