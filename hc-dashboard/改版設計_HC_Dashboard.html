HC Dashboard 改版設計文件

版本：草稿 v0.1 ／ 2026-06-12 對應規格：Notion「HC Dashboard」(2026/6/8 版) ／ 現行 sp_DSB_HC 決策前提：設定全部 config 表驅動；輸出表結構待定（本文第 1 節分析利弊並建議）

0. 設計總原則

把「會隨組織調整而變動的東西」（層級、排序、顯示名、Scorecard 對應、組合小計公式、各 Format 顯示哪些 KPI）全部抽到設定表。 SP 只負責三件事：抓來源 → 套設定算 → 寫輸出。日後組織調整 = 改表，不改 code。

資料計算拆成清楚的 5 個階段（4 個分頁共用同一套後段邏輯）：

Stage1 葉節點(Leaf)   每個最小單位從來源抓「可加總」KPI
        ↓
Stage2 Revenue        從 Scorecard 依對應抓 Revenue（也是可加總）
        ↓
Stage3 組合(Rollup)   依「誰加誰」設定，把子節點加總成小計/Total 列
        ↓
Stage4 YTM            可加總KPI：New Hires/Turnover=月加總；Total HC=月平均
        ↓
Stage5 衍生KPI        Turnover %、Revenue per Employee（比率，不能加總，最後算）
        ↓
輸出 ReportData

關鍵觀念：比率型 KPI（Turnover %、Revenue per Employee）絕對不能用加總得到， 必須先把分子分母（可加總KPI）各自 Rollup / YTM 完成，再對「每一列（含小計列）」個別相除。 現行 SP 對 Revenue per Employee 已是這樣做，新增的 Turnover % 沿用同模式。

1. 輸出表結構：單表 vs 4 表（利弊分析）

面向 方案A：單一 DSB_HC_ReportData 方案B：沿用 4 張 HC_Dashboard_SBU/RBU/Operation/COE
Schema HCDashbordType, Currency, Year, KPI, Measures, Value, Dimensions 4 張，維度欄各自叫 SBU/RBU/Operation/COE，欄名不一致
與新規格範例 一致（你給的 DataSource 範例就是單表） 不一致，需再轉一層
前端查詢 一支查詢 + WHERE HCDashbordType= + Format 用欄位篩 4 支查詢，分頁各接各表
新增分頁/Format 不動結構，加資料即可 可能要再開表
SP 寫法 後段 Stage3~5 完全共用、一次寫好 後段邏輯得複製 4 份（現行就是這樣，所以 SP 很長）
既有相依 需確認還有沒有別的程式吃舊 4 表 既有相依不動，風險低
單表資料量 4 類合一，列數變多；靠 HCDashbordType+索引即可 各表較小
遷移成本 前端查詢要改、舊表要退場 幾乎不動前端

建議：採方案A（單表）。 理由： 1. 你提供的新版 DSB_HC_ReportData 範例本身就是單表結構，代表規格方向已往這走。 2. config 驅動的後段邏輯（Rollup/YTM/衍生KPI）只有單表能寫一次共用，否則 4 份複製又回到現在難維護的老路。 3. Format 下拉只是「同一份資料挑不同 KPI 子集顯示」，用欄位篩最自然。

若顧慮既有相依，折衷：SP 先寫進單表 DSB_HC_ReportData，再用 4 個 VIEW 對應舊表名，讓舊程式無痛過渡，之後再退場。

本文後續 SP 草稿以 方案A 單表 撰寫。

2. 新舊規格差異對照清單（開發 checklist）

2-1 共通

  • 新增輸出表 DSB_HC_ReportData（單表，含 HCDashbordType、Measures）
  • 新增 KPI Turnover % = # of Turnover / ((當月 Total HC + 前月 Total HC)/2)；前端 <5% 綠、>10% 紅
  • 年月維度新增：By Year / 2025 Dec / 2026 1–12月 / YTM（YTM 對部分 KPI 顯示「-」）
  • 各架構名稱底下只顯示 Budget KPI（HC/Budget）
  • 篩選新增 Format：HC Management / Turnover / Revenue per Employee（僅 SBU、RBU）
  • Employee list link：只有 Format = HC Management 才顯示

2-2 SBU

  • 層級由 ~19 群組列 → 31 條明細 PG（iSystem-ISG/ESG/iMs/CE/Marketing/BDM…、iAutomation-、Embedded-、iService-*、WISE），照 SBU Hierarchy 排序
  • 每條 PG 的 Revenue 來源各自對應 Scorecard（PG=Intelligent System + 各自 PD/MD，詳 Notion 表）
  • KPI：Total HC(=−ACL+−Oversea+#LOA)、−ACL、−Oversea、#LOA、#New Hires、#Turnover、Revenue、Rev per Employee、HC/Budget、Turnover%(new)
  • 三個 Format 各顯示不同 KPI 子集（見 §4 KPIFormat）

2-3 RBU

  • 層級 7 區 → 19 列，新增 leaf：India、AAU、LATAM、ME&A、CIS、HQDC
  • 組合小計（Rollup）：
  • S.Asia Pacific Total = ASEAN + India + AAU
  • InterCon Total = LATAM + ME&A + CIS
  • InterCon & S.Asia Pacific w/o HQDC = S.Asia + InterCon
  • InterCon & S.Asia Pacific w/ HQDC = S.Asia + InterCon + HQDC
  • RBU Total (w/ HQDC) = ANA…AKR + S.Asia leaf群 + InterCon leaf群 + HQDC (+AURES?)
  • HQDC 不顯示 Revenue / Revenue per Employee
  • AURES 規格上被刪線（待確認是否保留）
  • KPI：Total HC、#New Hires、#Turnover、Turnover%(new)、Revenue、Rev per Employee、HC/Budget

2-4 Operation

  • 維持單頁、無 Format 下拉
  • 層級：ATMC/AKMC/AJMC → MSU(=三者加總) → Non-MSU → Operation Grand Total(=MSU+Non-MSU)(new)
  • KPI：Total HC(=IDL+DL+#LOA)、−IDL、−DL、#LOA、#New Hires(+IDL/DL拆)、#Turnover(+IDL/DL拆)、HC/Budget、Turnover%(new) + IDL/DL 拆(new)

2-5 COE（改動最大）

  • GA → GA/ER（改抓 RPT_Level1_Name='GA/ER'）
  • 新增：DMKT、BIOS & FW、CES、DQA Linkou、Wireless TSU、IoTMart
  • 移除：Design、CM&D、COE Grand Total
  • 新增組合：
  • Corp.Function All = HR+IT+Finance+GA/ER+DMKT+COE-Other
  • HW Engineering All = BIOS&FW+CES+DQA Linkou+Wireless TSU
  • Corp BG All = IoTMart
  • KPI：Total HC(=Total HC+#LOA)、#LOA、#New Hires、#Turnover、HC/Budget、Turnover%(new)

2-6 ⚠ 範例資料髒值（請資料整理端 Amber 修正後再進表）

  • Operation 有 #NAME?（Excel 公式錯誤殘留）
  • COE：BIOS & FM vs BIOS & FW、COE_Others vs COE-Others 拼法不一
  • Operation：MSU / MSU Total / MSU Others 混用，需統一命名
  • 這些字串若直接進正式表，會破壞 config 對應與前端排序 → Measures 命名要與 HierarchySort 完全一致

3. 設定表（config）欄位設計

3-1 DSB_HC_Hierarchy（核心：定義每個分頁有哪些列、怎麼排、資料從哪來）

取代現行 DSB_HC_HierarchySort + DSB_HC_ShortName 的層級/顯示/來源對應職責。

欄位 型別 說明
HCDashbordType nvarchar(25) SBU / RBU / Operation / COE
Sort int 前端列排序
Measures nvarchar(200) 前端顯示的列名（唯一鍵之一），須與輸出 Measures 一致
NodeType nvarchar(10) Leaf＝直接從來源抓；Rollup＝由其他列加總
HcSourceKey nvarchar(100) Leaf 用：對應 rv_hr_hc_dashboard.RPT_Level1_Name
ShowRevenue bit 是否顯示 Revenue / Rev per Employee（HQDC=0）
IsActive bit 停用列免刪，設 0 即可

3-2 DSB_HC_Rollup（組合公式：誰加誰）

欄位 型別 說明
HCDashbordType nvarchar(25) 分頁
ParentMeasures nvarchar(200) 組合列名（須在 Hierarchy 中 NodeType=Rollup）
ChildMeasures nvarchar(200) 被加總的子列名（可為 Leaf 或另一個 Rollup）

一個組合列 = 多筆 Child。多層組合（例：InterCon & S.Asia w/ HQDC 含 S.Asia Total、InterCon Total 兩個自己也是組合的列）由 SP 用遞迴 CTE 展開到葉節點再加總，避免重複計算。

3-3 DSB_HC_ScorecardMap（Revenue 來源對應）

欄位 型別 說明
HCDashbordType nvarchar(25) SBU / RBU
Measures nvarchar(200) 對應 Hierarchy 的列名
ScorecardSource nvarchar(50) SCORECARD_PROD_N(SBU) / SCORECARD_RBU_2011(RBU)
FilterPG nvarchar(100) SBU：PROD_GROUP（多為 Intelligent System）
FilterPD nvarchar(100) SBU：PROD_DIVI（All / AiCS / AiH…）；RBU 用 REGION
Description nvarchar(50) Revenue(E2E)(SBU) / Revenue(RBU)

3-4 DSB_HC_KPIFormat（各 Format 顯示哪些 KPI、型別、排序）

欄位 型別 說明
HCDashbordType nvarchar(25) 分頁
Format nvarchar(30) HC Management/Turnover/Revenue per Employee；Operation/COE 留空＝單頁
KPI nvarchar(100) KPI 名
KpiSort int 顯示順序
ValueType nvarchar(10) number / percent
HideOnYTM bit YTM 欄是否顯示「-」

§3-4 主要供前端決定每個 Format 顯示哪幾列 KPI 與顏色規則；後端也可用它過濾輸出。

4. 改寫後 SP 草稿（方案A 單表，config 驅動）

以下為結構草稿，示範 config 驅動的 5 階段管線。 Stage1 各分頁來源欄位不同（SBU 有 ACL/Oversea、Operation 有 IDL/DL），仍需分塊抽取； 但 Stage3（Rollup）、Stage4（YTM）、Stage5（衍生KPI）完全共用、只寫一次——這是相對現行 SP 最大的簡化。

ALTER PROCEDURE [dbo].[sp_DSB_HC_New]
AS
BEGIN
    SET NOCOUNT ON;
    DECLARE @Year int = YEAR(GETDATE());
    DECLARE @CurMonth int = MONTH(GETDATE());

    -- 統一中繼表（取代現行 4 張 #暫存表）
    CREATE TABLE #Stage (
        HCDashbordType nvarchar(25),
        Currency       nchar(3),
        Year           int,
        KPI            nvarchar(100),
        Measures       nvarchar(200),   -- 已是「顯示名」
        Value          float,
        Dim            int               -- 1~12 月、13=YTM
    );

    /*==================================================================
      STAGE 1 — 葉節點 HC（可加總 KPI），各分頁來源欄位不同故分塊
      重點：用 Hierarchy.HcSourceKey 對應 RPT_Level1_Name，
            直接輸出 Measures = Hierarchy.Measures（不再 SP 內寫死群組）
    ==================================================================*/
    -- 範例：SBU（其餘 RBU/Operation/COE 同模式，差在 UNPIVOT 的 KPI 欄位清單）
    ;WITH Src AS (
        SELECT 'USD' AS Currency, [ThisYear] AS Year,
               [RPT_Level1_Name] AS HcSourceKey,
               CAST([ThisMonth] AS int) AS Dim,
               [Total HC],[# of New Hires],[# of Turnover],[ACL],[Oversea],[# of LOA]
        FROM OPENQUERY("DENODO-PROD",'SELECT * FROM hcm.rv_hr_hc_dashboard')
        WHERE [rpt_type]='SBU' AND [ThisYear] >= 2022
    )
    INSERT INTO #Stage (HCDashbordType,Currency,Year,KPI,Measures,Value,Dim)
    SELECT 'SBU', u.Currency, u.Year, u.KPI, h.Measures, u.Value, u.Dim
    FROM Src
    UNPIVOT (Value FOR KPI IN
            ([Total HC],[# of New Hires],[# of Turnover],[ACL],[Oversea],[# of LOA])) u
    JOIN [dbo].[DSB_HC_Hierarchy] h
         ON h.HCDashbordType='SBU' AND h.NodeType='Leaf'
        AND h.HcSourceKey = u.HcSourceKey;
    --  ↑ RBU / Operation / COE 重複此段，改 rpt_type 與 UNPIVOT KPI 清單
    --    （Operation 多 IDL/DL/New Hires IDL…；COE 排除 Marketing、GA→GA/ER）

    /*==================================================================
      STAGE 2 — Revenue（也是可加總），用 ScorecardMap 對應
    ==================================================================*/
    -- 範例：SBU Revenue
    ;WITH Rev AS (
        SELECT 'USD' AS Currency, s.[YEAR_ID] AS Year, m.Measures,
               s.[M01],s.[M02],s.[M03],s.[M04],s.[M05],s.[M06],
               s.[M07],s.[M08],s.[M09],s.[M10],s.[M11],s.[M12]
        FROM [Global_Fin].[dbo].[SCORECARD_PROD_N] s
        JOIN [dbo].[DSB_HC_ScorecardMap] m
             ON m.HCDashbordType='SBU'
            AND m.FilterPG = s.[PROD_GROUP]
            AND m.FilterPD = s.[PROD_DIVI]
        WHERE s.[DESCRIPTION]='Revenue(E2E)' AND s.[YEAR_ID] >= @Year
    )
    INSERT INTO #Stage (HCDashbordType,Currency,Year,KPI,Measures,Value,Dim)
    SELECT 'SBU', Currency, Year, 'Revenue', Measures, Value,
           CAST(REPLACE(MonthCol,'M','') AS int)
    FROM Rev
    UNPIVOT (Value FOR MonthCol IN
            ([M01],[M02],[M03],[M04],[M05],[M06],[M07],[M08],[M09],[M10],[M11],[M12])) u;
    -- RBU Revenue 同模式，來源換 SCORECARD_RBU_2011、對應 REGION

    /*==================================================================
      STAGE 3 — 組合(Rollup)：遞迴展開到葉節點再加總（可加總 KPI 才做）
      一次處理所有分頁、所有組合列
    ==================================================================*/
    ;WITH Expand AS (
        -- 起點：每個組合列的直接子節點
        SELECT r.HCDashbordType, r.ParentMeasures, r.ChildMeasures
        FROM [dbo].[DSB_HC_Rollup] r
        UNION ALL
        -- 遞迴：子節點若本身也是組合，繼續往下展開到葉節點
        SELECT e.HCDashbordType, e.ParentMeasures, r.ChildMeasures
        FROM Expand e
        JOIN [dbo].[DSB_HC_Rollup] r
             ON r.HCDashbordType=e.HCDashbordType
            AND r.ParentMeasures = e.ChildMeasures
    ),
    LeafOnly AS (   -- 只留展開後仍是葉節點的 child
        SELECT DISTINCT e.HCDashbordType, e.ParentMeasures, e.ChildMeasures
        FROM Expand e
        JOIN [dbo].[DSB_HC_Hierarchy] h
             ON h.HCDashbordType=e.HCDashbordType
            AND h.Measures=e.ChildMeasures AND h.NodeType='Leaf'
    )
    INSERT INTO #Stage (HCDashbordType,Currency,Year,KPI,Measures,Value,Dim)
    SELECT s.HCDashbordType, s.Currency, s.Year, s.KPI,
           lo.ParentMeasures, SUM(s.Value), s.Dim
    FROM #Stage s
    JOIN LeafOnly lo
         ON lo.HCDashbordType=s.HCDashbordType AND lo.ChildMeasures=s.Measures
    WHERE s.KPI NOT IN ('Turnover %','Revenue per Employee')   -- 只加可加總KPI
    GROUP BY s.HCDashbordType,s.Currency,s.Year,s.KPI,lo.ParentMeasures,s.Dim;

    /*==================================================================
      STAGE 4 — YTM（Dim=13）
        New Hires / Turnover 類 = 月加總
        Total HC / ACL / Oversea / LOA = 月平均（/已過月數）
        Revenue = 月加總
    ==================================================================*/
    INSERT INTO #Stage (HCDashbordType,Currency,Year,KPI,Measures,Value,Dim)
    SELECT HCDashbordType,Currency,Year,KPI,Measures,
           CASE WHEN KPI IN ('Total HC','ACL','Oversea','# of LOA','- IDL','- DL')
                THEN SUM(Value)/NULLIF(@CurMonth-1,0)   -- 平均
                ELSE SUM(Value) END,                    -- 加總
           13
    FROM #Stage
    WHERE Year=@Year AND Dim < @CurMonth
      AND KPI NOT IN ('Turnover %','Revenue per Employee')
    GROUP BY HCDashbordType,Currency,Year,KPI,Measures;

    /*==================================================================
      STAGE 5 — 衍生 KPI（比率，對每一列含小計個別計算）
    ==================================================================*/
    -- 5a. Revenue per Employee = Revenue / Total HC
    INSERT INTO #Stage (HCDashbordType,Currency,Year,KPI,Measures,Value,Dim)
    SELECT r.HCDashbordType,r.Currency,r.Year,'Revenue per Employee',
           r.Measures, r.Value / NULLIF(hc.Value,0), r.Dim
    FROM #Stage r
    JOIN #Stage hc
         ON hc.HCDashbordType=r.HCDashbordType AND hc.Currency=r.Currency
        AND hc.Year=r.Year AND hc.Measures=r.Measures AND hc.Dim=r.Dim
        AND hc.KPI='Total HC'
    WHERE r.KPI='Revenue';

    -- 5b. Turnover % = #Turnover / ((當月 + 前月 Total HC)/2)
    INSERT INTO #Stage (HCDashbordType,Currency,Year,KPI,Measures,Value,Dim)
    SELECT t.HCDashbordType,t.Currency,t.Year,'Turnover %',t.Measures,
           t.Value / NULLIF((hc.Value + ISNULL(pm.Value,hc.Value))/2.0,0), t.Dim
    FROM #Stage t
    JOIN #Stage hc
         ON hc.HCDashbordType=t.HCDashbordType AND hc.Currency=t.Currency
        AND hc.Year=t.Year AND hc.Measures=t.Measures AND hc.Dim=t.Dim
        AND hc.KPI='Total HC'
    LEFT JOIN #Stage pm   -- 前月 Total HC
         ON pm.HCDashbordType=t.HCDashbordType AND pm.Currency=t.Currency
        AND pm.Year=t.Year AND pm.Measures=t.Measures AND pm.Dim=t.Dim-1
        AND pm.KPI='Total HC'
    WHERE t.KPI='# of Turnover' AND t.Dim BETWEEN 1 AND 12;

    /*==================================================================
      STAGE 6 — Budget（每月該月 budget；維度=Budget）
    ==================================================================*/
    -- 同現行：抓 rv_sharepoint_hc_dashboard_budget，依 rpt_type 寫入，
    --         Measures 用 Hierarchy 對應名（略）

    /*==================================================================
      OUTPUT — 寫入單表 DSB_HC_ReportData（Dim 轉月份字串）
    ==================================================================*/
    DELETE [Global_Fin].[dbo].[DSB_HC_ReportData] WHERE [Year]=@Year;

    INSERT INTO [Global_Fin].[dbo].[DSB_HC_ReportData]
        (HCDashbordType,Currency,Year,KPI,Measures,Value,Dimensions)
    SELECT HCDashbordType, RTRIM(Currency), Year, KPI, Measures, Value,
           CASE Dim WHEN 1 THEN 'Jan' WHEN 2 THEN 'Feb' WHEN 3 THEN 'Mar'
                    WHEN 4 THEN 'Apr' WHEN 5 THEN 'May' WHEN 6 THEN 'Jun'
                    WHEN 7 THEN 'Jul' WHEN 8 THEN 'Aug' WHEN 9 THEN 'Sep'
                    WHEN 10 THEN 'Oct' WHEN 11 THEN 'Nov' WHEN 12 THEN 'Dec'
                    WHEN 13 THEN 'YTM' END
    FROM #Stage
    WHERE Year=@Year;

    DROP TABLE #Stage;
END
